# SolveLang AI-search measurement

Baseline date: 2026-08-04. Record indexed pages, branded and non-branded query visibility, source citations, and identifiable AI-referral sessions from Search Console, Bing Webmaster Tools, and analytics before comparing subsequent months.

Monthly, test every question in `data/ai-search-prompts.json` in Google, Bing/Copilot, ChatGPT Search, Claude search, and Perplexity where available. Record the result, cited URL, whether the answer correctly preserves beta/preview/Studio boundaries, and any conversion. Review sitemap errors, index coverage, canonical selection, structured-data reports, and crawler access. This is a method, not an AI-visibility score or a guarantee of citation.
