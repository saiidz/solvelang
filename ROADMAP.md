# SolveLang Roadmap

SolveLang is an early programming language prototype created by Saiid Zeidan.

## Completed

- Public GitHub repository
- Rust-based interpreter
- Variables
- Print statements
- Integer math: `+`, `-`, `*`, `/`
- If / else statements
- Comparison operators
- Functions
- While loops
- Basic arrays
- Return values
- Multiple function parameters
- Booleans
- String joining using `..`
- Organized Rust module structure

## Next Priorities

### 1. Better Language Core

- Better parser and lexer
- Cleaner error messages with line numbers
- Real value types instead of storing everything as strings
- Nested expressions
- Operator precedence improvements

### 2. More Language Features

- For loops
- Imports
- Objects / records
- Standard library
- File reading and writing
- JSON support

### 3. Developer Tooling

- `solvec run file.solve`
- Formatter
- Linter
- VS Code syntax highlighting
- Tests
- Documentation website

### 4. Web and Automation Direction

- HTTP server support
- HTML templates
- Form handling
- Database support
- AI agent primitives

## Long-Term Vision

SolveLang aims to become a simple, readable, safe, and AI-native language for modern apps, automation, APIs, and intelligent systems.
