# ANPC SAL Pictogram Provenance

The homepage uses `site/public/anpc-sal-pictogram.png`, copied without alteration from the official ANPC attachment published with its April 2026 notice: <https://anpc.ro/wp-content/uploads/2026/04/Anexa-2-pictograma.docx>.

It is displayed at exactly 250 by 50 CSS pixels and links to <https://reclamatiisal.anpc.ro>. This follows Romania's current ANPC SAL notice and Order no. 270/2026. The historic EU SOL/ODR platform must not be presented as an available complaint route because the ANPC notice states it has been discontinued.

Before enabling production checkout, the owner must independently confirm the current official asset, destination, and any applicability to the Operator with qualified Romanian/EU consumer-law advice.
