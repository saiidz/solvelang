# Pricing and Service Packages

_Last updated: 2026-08-06. These are pricing hypotheses to test, not established market rates._

## Pricing principles

SolveLang should sell scoped business outcomes before it sells software access. Use fixed-fee packages where the problem and deliverables are clear, then quote implementation separately when scope is uncertain.

Never present the numbers below as proven willingness-to-pay. Adjust them after real discovery calls and paid pilots.

## Offer 1: Workflow Clarity Audit

**Purpose:** turn a messy or undocumented business process into a readable, reviewable workflow specification.

**Suggested hypothesis:** $750-$2,500 depending on scope.

**Deliverables:**
- stakeholder interview
- current-state workflow map
- pain-point and failure-path inventory
- deterministic vs AI-assisted decision map
- approval/human-review points
- recommended implementation path
- readable SolveLang-style specification or equivalent evidence artifact

**Excludes:** production integrations, unattended execution, compliance certification, or guaranteed ROI.

## Offer 2: Workflow Prototype Sprint

**Purpose:** prove one narrow use case end to end using SolveLang artifacts and the client's agreed execution platform.

**Suggested hypothesis:** $2,500-$7,500.

**Deliverables:**
- approved use-case definition
- workflow specification
- prototype implementation in the agreed stack
- test cases and failure cases
- handoff notes
- next-step estimate

## Offer 3: Automation Rescue and Documentation

**Purpose:** make fragile Zapier, Make, n8n, Pipedream, or custom workflows understandable and maintainable.

**Suggested hypothesis:** $1,500-$5,000.

**Deliverables:**
- inventory of current automations
- duplicated/hidden logic review
- AI-risk and human-approval review
- simplified target workflow
- documentation and maintenance recommendations

## Offer 4: Implementation Engagement

Quoted after discovery. Implementation may use the client's existing tools instead of SolveLang as the execution runtime.

Typical scope can include:
- workflow build/refactor
- API integration
- model/provider integration
- testing and acceptance criteria
- deployment support
- rollback and failure-handling plan
- documentation

## Monthly maintenance

**Suggested hypothesis:** $500-$2,500+/month depending on number and criticality of workflows.

Possible services:
- failure review
- change requests
- workflow documentation updates
- model/provider cost review
- quarterly workflow audit
- incident and dependency review

## Pricing guardrails

Do not quote based only on number of steps. Price should reflect business criticality, integration complexity, data sensitivity, approval requirements, and support burden.

Do not include open-ended support in a fixed-scope project. Define response expectations and exclusions explicitly.
