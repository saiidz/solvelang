# Live main-protection evidence after v0.3.0

Ruleset `Protect main` (`18206723`) is active for the default branch with no bypass actors.

It enforces:

- deletion protection;
- non-fast-forward protection;
- pull requests before merge;
- required review-thread resolution;
- strict up-to-date required status checks;
- `Rust runtime`;
- `Static site`;
- `SolveLang Rust security and tests`;
- `WASM artifact security`.

Required approving review count remains 0, matching the repository governance contract until a reliable non-author reviewer exists.
