# SolveLang MCP Server v0.2.0

## Highlights

- Analyze n8n workflow JSON supplied directly through `rawJson` without creating a file.
- Keep raw workflow content in memory only; it is not written, logged, or sent over the network.
- Preserve workspace-relative file analysis for existing Codex and Claude integrations.
- Return deterministic schema `solvelang.mcp.n8n-preflight.v2` output with `pass`, score, severity counts, evidence, and remediation guidance.
- Reject malformed JSON without echoing sensitive input.
- Enforce the existing 2 MB payload and 5,000-node safety limits before analysis.
- Expand automated coverage from 3 to 7 MCP tests, including deterministic output and privacy boundaries.

## Compatibility

The four MCP tool names remain unchanged. Existing path-based client configurations continue to work. The new `rawJson` input is additive.

## Release process

Publish only from the protected `npm-production` environment using npm Trusted Publishing. The release tag must be `v0.2.0` and must point to the commit where `packages/mcp-server/package.json` reports version `0.2.0`.
