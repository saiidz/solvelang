# Stop condition

The no-credit repository loop is exhausted when:

- current repository defects found by the audit are fixed and merged;
- required CI is green on the merge;
- release/npm/install-boundary evidence is recorded;
- #898/#113 reflect current truth; and
- every remaining incomplete item requires external administrator action, independent evaluation, provider credits/execution, public listing/review, production credentials, or separately scoped production authorization.

At that point, do not invent repository work to avoid an external gate.
