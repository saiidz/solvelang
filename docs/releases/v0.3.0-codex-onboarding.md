# Install SolveLang v0.3.0 in Codex

For an eligible managed Codex workspace:

1. Have a workspace administrator import the GitHub marketplace from `https://github.com/saiidz/solvelang`.
2. Leave the import Path blank/use the repository root so Codex can read `.agents/plugins/marketplace.json`.
3. Select/install **SolveLang** for Codex.
4. Start a fresh Codex session after installation.
5. Confirm the SolveLang MCP server starts and its tools are discoverable.
6. Exercise a deterministic/read-only SolveLang tool and record non-sensitive evidence.

The canonical plugin launches `@solvelang/mcp-server@0.3.0` through `npx`.

Workspace import/install is separate from global public Plugin Directory publication. Do not claim global listing based only on a managed-workspace import.
