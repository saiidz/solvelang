# v0.3.0 completion scope

`v0.3.0` completion here means the checked-in MCP/plugin version transition, GitHub Release, trusted npm publication workflow, canonical v0.3.0 plugin pin, and repository verification evidence are complete.

It intentionally excludes managed-workspace administration, global Plugin Directory publication, independent evaluation, provider-credit execution, billing/provider activation, support activation, analytics live canaries, and other protected production mutations.
