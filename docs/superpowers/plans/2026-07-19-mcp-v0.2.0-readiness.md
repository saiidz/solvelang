# SolveLang MCP v0.2.0 readiness plan

## Goal

Prepare a backward-compatible MCP release that accepts n8n workflow exports directly as bounded raw JSON while preserving the local-first privacy model.

## Scope

- Accept exactly one n8n input source: a workspace-relative `path` or in-memory `rawJson`.
- Enforce the existing 2 MB and 5,000-node limits for both input modes.
- Reject malformed JSON with sanitized errors that do not echo workflow content.
- Keep raw JSON in memory only; do not write, log, retain, or transmit it.
- Return deterministic evidence, finding order, severity counts, score, and a CI-friendly `pass` boolean.
- Preserve read-only MCP annotations and all current workspace confinement rules.
- Update package and client documentation.

## Release gates

1. TypeScript build succeeds on supported Node versions.
2. Unit tests cover raw input, malformed input, byte limits, node limits, disabled safeguards, deterministic output, and path escape rejection.
3. Packed consumer installation and executable smoke test pass.
4. Repository MCP CI, Rust CI, and main CI are green.
5. Package version remains `0.1.0` in this readiness PR.
6. No npm publication, GitHub tag, GitHub Release, deployment, or AWS resource is created.

## Follow-up release

After this PR is merged and verified in local Codex and Claude clients, prepare a separate release PR that changes the package version to `0.2.0`, updates the lockfile and changelog, reruns packed verification, and uses the existing protected Trusted Publishing workflow.
