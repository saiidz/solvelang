# Outreach Tracker

Use this tracker to keep manual Workflow X-Ray Audit outreach small, personal, and easy to follow up.

## Rules

- Send 10 messages at a time.
- Personalize the first line around a real pain signal.
- Link to the support triage demo first if they need context: https://www.solve-lang.com/demo/support-triage/
- Link to the audit page when asking them to send a workflow: https://www.solve-lang.com/audit/
- Stop after one follow-up unless they engage.
- Track every message here before sending the next batch.
