# SolveLang Workflow Audit Offer

## Who It Is For

- Founders/operators
- Small teams
- Agencies/consultants
- Support-heavy SaaS
- People manually routing emails, leads, tasks, reports, or requests

## What The Customer Sends

- One messy workflow
- Tools involved
- What starts it
- Manual decisions
- Desired output
- What success looks like

## What They Get

- Plain-English workflow map
- SolveLang-style workflow draft
- Suggested automation path
- Tools/integrations list
- Human review points
- Next-step recommendation
- Optional custom setup quote

## Suggested Starting Price

Early fixed-scope workflow audits can start around `$300-$500` depending on complexity.

This is not hardcoded pricing on the website. It is an internal starting point for written quotes after the workflow is understood.

## Boundaries

- No production credentials required for the audit
- No backend access required before scoping
- No regulated autonomous decisions
- No promise of full automation before mapping
- No checkout, subscription, or payment flow before a real workflow need is clear
