# First Sale Checklist

Use this before and during the first Workflow X-Ray Audit outreach push.

## Pre-Outreach Checks

- [ ] Verify the website loads: https://www.solve-lang.com/
- [ ] Verify the demo page loads: https://www.solve-lang.com/demo/support-triage/
- [ ] Verify the audit page loads: https://www.solve-lang.com/audit/
- [ ] Verify the browser preview loads: https://www.solve-lang.com/run/
- [ ] Verify the Open Gmail draft CTA opens Gmail.
- [ ] Verify `hello@solve-lang.com` is visible and copyable.

## Outreach Batch

- [ ] Send 10 outreach messages.
- [ ] Personalize each first line around a real pain signal.
- [ ] Link to the support triage demo when the prospect needs context.
- [ ] Link to the audit page when asking the prospect to send a workflow.
- [ ] Track every message in [docs/outreach-tracker.md](outreach-tracker.md).
- [ ] Send only one polite follow-up after 3-5 days unless they engage.

## When Someone Replies

- [ ] Ask for one messy workflow, not a broad automation wish list.
- [ ] Ask what starts the workflow.
- [ ] Ask what tools are involved.
- [ ] Ask what decisions happen manually today.
- [ ] Ask what output should happen.
- [ ] Ask what would make the workflow successful.
- [ ] Quote `$300-$500` only after the workflow is clear.

## Delivery

- [ ] Deliver the audit using [docs/first-audit-playbook.md](first-audit-playbook.md).
- [ ] Include the current workflow map.
- [ ] Include hidden decisions.
- [ ] Include missing branches.
- [ ] Include human review points.
- [ ] Include a SolveLang-style workflow draft.
- [ ] Include the automation path.
- [ ] Include the setup recommendation.
- [ ] Save any useful proof for a future case study, with permission.
