# LinkedIn Summary

I build systems where software architecture, AI workflows, developer tooling, and business-process design meet.

My current portfolio project, SolveLang, is an early Rust-based workflow language designed to make AI-assisted business processes readable, version-controllable, auditable, and easier to review. The project includes a lexer, parser, AST runtime, source-located diagnostics, runtime safety policies, a local-first workflow analysis Studio, browser product surfaces, and experimental API/subscription infrastructure built with AWS and Stripe.

A major design principle is separating deterministic business logic from model-driven behavior. SolveLang deliberately labels what works today, what is experimental, and what is planned instead of presenting a prototype as a production automation platform.

The project has given me hands-on experience across Rust, TypeScript/Next.js, AWS Lambda/SAM, DynamoDB, IAM, Stripe, API authentication, testing, CI/CD troubleshooting, developer experience, AI integration, product strategy, and technical documentation.

I am especially interested in AI engineering, software/platform engineering, solutions and implementation engineering, developer relations, technical product, and AI automation roles where I can translate messy business problems into understandable, testable technical systems.
